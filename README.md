# XAI-Research
Leakage-controlled credit risk benchmarking and XAI fairness audit on the Statlog Australian Credit dataset. Compares Logistic Regression, Random Forest, XGBoost, a Deep Gated Tabular Network (DGTN), and a Platt-calibrated Hybrid-TabNet-Ensemble using TreeSHAP, LIME, and sensitive-proxy attribution analysis.
